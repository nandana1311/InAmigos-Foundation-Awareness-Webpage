# InAmigos Foundation — Awareness Webpage

A static awareness webpage created for the InAmigos Foundation NGO as part of the intern task.

## 🌐 Live Demo
[Click here to view](https://nandana1311.github.io/InAmigos-Foundation-Awareness-Webpage/)

## 📋 About the Project
This webpage was built to spread awareness about InAmigos Foundation's projects and initiatives. It includes:
- Introduction about the NGO
- Details of 6 flagship projects (SEVA, BACHPANSHALA, JEEV, UDAAN, PRAKRITI, VIKAS)
- Social impact statistics
- Call to action for volunteers and partners

## 🛠️ Built With
- HTML5
- CSS3

## 🏢 About InAmigos Foundation
InAmigos Foundation is a registered Section 8 NGO founded on September 23, 2020, working across education, environment, health, women empowerment and rural development in India.
